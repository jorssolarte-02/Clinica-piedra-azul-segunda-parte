CLÍNICA PIEDRA AZUL - ANGULAR
================================

EJECUCIÓN
---------
1. Abrir una terminal dentro de esta carpeta, donde está package.json.
2. Ejecutar:
   npm install
3. Iniciar el proyecto:
   npm start
4. Abrir en el navegador:
   http://localhost:4200/
